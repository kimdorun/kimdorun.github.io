# ads.txt — 생활금융 계산기 허브
# 배포 도메인: https://kimdorun.github.io
#
# [사용 방법]
# 1. Google AdSense 승인 후 아래 주석 처리된 한 줄의 주석(#)을 해제합니다.
# 2. pub-XXXXXXXXXXXXXXXX 를 애드센스에 표시되는 실제 게시자 ID로 교체합니다.
#    (예: google.com, pub-1234567890123456, DIRECT, f08c47fec0942fa0)
# 3. 파일명은 ads.txt, 위치는 사이트 루트(https://kimdorun.github.io/ads.txt)여야 합니다.
# 4. 변경 후 https://kimdorun.github.io/ads.txt 에서 반영 여부를 확인합니다.
#
# 주의: 승인 전에는 아래 줄을 주석 상태로 두어 잘못된 게시자 ID가 배포되지 않도록 합니다.

# google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
